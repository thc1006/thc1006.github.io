F3 · 旁邊的模型服務

誰付出真正的推論算力？

託管模型 API
F2 發 HTTPS；供應商在自己的 GPU / 加速器叢集推論。你不必為每個 Agent 配 GPU。
自架模型
F2 發 HTTPS 給你的 vLLM；vLLM 在相容硬體載入模型權重、排程推論、回傳結果。

Agent 1、Agent 2 可共用同一個模型 endpoint。它們仍有不同角色、session、工具與權限，不能因此共享全部 memory。

算力也不是只由 LLM 使用：驗證器和 solver 用 CPU；Robot 用本機控制運算；需要視覺模型時可另有 edge GPU。這些不會自動變成 A2A Agent。

模型服務提供推論，A2A 傳遞工作；它們不是同一條介面。[S09]

三種「Graph」請不要混為一談

Mission Graph

任務的節點、依賴、branch、approval、completion contract。由 F1 解譯。

Harness 的局部 loop

一次規劃中反覆 model → tools → model。它可有自己的內部圖，但不是任務真相。

Robot 的 Behavior Tree

導航／技能內部執行與 recovery。它不是 A2A，也不是 LLM 推理圖。

mission_id 不等於 trace_id，A2A Task 不等於 Temporal Activity，也不等於 ROS Action。長任務可含多個 traces，以 span links 和領域 ID 關聯；不同 A2A server 的 contextId 不保證相同。HTTP 的 traceparent 不會自動穿過 DDS 或 vendor API。[S01 S12 S17]

Trace / Log / Metric

執行路徑、事件、統計；容許既定採樣與保留策略。用於診斷，不單獨決定交付。

Proof / Effect Ledger

哪個版本為何獲准、是否下發、結果是否不明。寫入受控 domain DB，不能因 trace sampling 被丟掉。

World Evidence

條碼、位置、接收確認、時間與來源。原始錄製可用 rosbag2 / MCAP；只有具來源與契約的資料才能結案。

各層實際從哪裡把紀錄傳出？

對方是黑箱 A2A server 時，只能先看到請求、回應與對方揭露的 artifact，不能假設可看其內部 LLM／工具 trace。託管模型通常也看不到供應商內部 GPU timeline。不要記錄秘密或隱藏推理全文；預設記 structured decision、必要輸入摘要與證據引用。
